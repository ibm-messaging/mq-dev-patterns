# Container Deployment of IBM MQ Queue Manager

These samples contain examples of how to deploy an IBM MQ Advanced for Developers queue manager container onto various platforms and using various tools.

## Options

| Directory | Description |
|---|---|
| [`compose`](compose/) | Deploy locally using Docker Compose or Podman Compose |
| [`copilot`](copilot/) | Deploy to AWS ECS Fargate using the AWS Copilot CLI |
| [`terraform-aws`](terraform-aws/) | Deploy to AWS ECS Fargate using Terraform or OpenTofu |
| [`cdk-aws`](cdk-aws/) | Deploy to AWS ECS Fargate using AWS CDK in Python with a declarative YAML configuration |
